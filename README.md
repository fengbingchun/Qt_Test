# Qt_Test
## The main role of the project:
- Qt Widgets Application test code
    - display images in real time through QLabel
    - qss's usage
    - menu bar's usage
    - tool bar's usage
    - vertical and horizontal layout's usage
    - display date and time
- Qt Quick Application test code
- Qt Console Application test code

## The dependent third-party libraries include:
- [OpenCV 4.10.0](https://github.com/opencv/opencv)
- [spdlog 1.14.1](https://github.com/gabime/spdlog)
- [SQLite 3.47.0](https://github.com/sqlite/sqlite)

## The project support platform:
- It supports Windows10:
    - Visual Studio's version is 2022
    - Qt's version is 6.8.0
    - CMake build(file position: prj/cmake)
